## RateLimitMiddleware\.ExecuteAsync\(CurlContext, Func\<Task\<CurlResult\>\>\) Method

Waits, if needed, until another request may run within the per\-second limit, then runs the rest of the pipeline
and records when it finished \(also when it failed\)\.

### Remarks

Example: the 11th request within one second on a `UseRateLimit(10)` pipeline waits until the first of
            those ten is a second old.
