## Curl\.ToHttpClient\(string\) Method

Translates a curl command into equivalent C\# `HttpClient` code, for learning what the command does or
for moving a request to plain `HttpClient`\.

```csharp
public static string ToHttpClient(string command);
```
#### Parameters

<a name='CurlDotNet.Curl.ToHttpClient(string).command'></a>

`command` [System\.String](https://learn.microsoft.com/en-us/dotnet/api/system.string 'System\.String')

The curl command line to translate, read with [DefaultFlavor](CurlDotNet.Curl.DefaultFlavor.md 'CurlDotNet\.Curl\.DefaultFlavor'), for example
            `curl -H 'Accept: application/json' https://api.example.com`\.

#### Returns
[System\.String](https://learn.microsoft.com/en-us/dotnet/api/system.string 'System\.String')  
C\# source text \(several lines, starting with a `// Generated by CurlDotNet from: ...` comment\) that
            sends the same request with `HttpClient`\.

#### Exceptions

[System\.ArgumentNullException](https://learn.microsoft.com/en-us/dotnet/api/system.argumentnullexception 'System\.ArgumentNullException')  
[command](CurlDotNet.Curl.ToHttpClient(string).md#CurlDotNet.Curl.ToHttpClient(string).command 'CurlDotNet\.Curl\.ToHttpClient\(string\)\.command') is null, empty or whitespace\. Fix: pass a
            command with a URL\. See https://github\.com/jacob\-mellor/curl\-dot\-net/blob/master/docs/how\-to/convert\-curl\-to\-csharp/README\.md

[CurlInvalidCommandException](CurlDotNet.Exceptions.CurlInvalidCommandException.md 'CurlDotNet\.Exceptions\.CurlInvalidCommandException')  
The command text cannot be read \(unterminated quote, option
            without its value\); the message names the problem\.

[CurlException](CurlDotNet.Exceptions.CurlException.md 'CurlDotNet\.Exceptions\.CurlException')  
Another parse error, such as a file named with `-d @file` that cannot be read\.

### Example

```csharp
string code = Curl.ToHttpClient(@"curl -X POST https://api.example.com/users \
    -H 'Authorization: Bearer token123' -d '{""name"":""John""}'");
Console.WriteLine(code);
```

### Remarks

The generated code covers the method, URL, headers, body, basic credentials (`-u`), proxy
            (`-x`), `-k` and `-L`; options with no `HttpClient` equivalent are left out. Because
            `HttpClient` follows redirects by default and curl does not, a command without `-L` produces a handler
            with `AllowAutoRedirect = false`, so the generated code sees the same 3xx response curl would. Nothing is
            sent. The output contains any password or token from the command in clear text, so do not log it.

Example: `string code = Curl.ToHttpClient("curl -X POST -H 'Content-Type: application/json' -d '{\"a\":1}' https://api.example.com");`
            returns code that builds an `HttpRequestMessage(HttpMethod.Post, ...)` with a `StringContent` body.
