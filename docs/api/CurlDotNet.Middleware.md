## CurlDotNet\.Middleware Namespace

| Classes | |
| :--- | :--- |
| [AuthenticationMiddleware](CurlDotNet.Middleware.AuthenticationMiddleware.md 'CurlDotNet\.Middleware\.AuthenticationMiddleware') | Adds `Authorization: Bearer <token>` to every request, asking your token provider for the token each time \(so a provider that refreshes expired tokens keeps requests authorised\)\. |
| [CachingMiddleware](CurlDotNet.Middleware.CachingMiddleware.md 'CurlDotNet\.Middleware\.CachingMiddleware') | Answers repeated GET requests from an in\-memory cache for a fixed time \(5 minutes by default\) instead of sending them again; only successful \(2xx\) results are stored\. |
| [CurlContext](CurlDotNet.Middleware.CurlContext.md 'CurlDotNet\.Middleware\.CurlContext') | Everything middleware needs to know about one request: the curl command, the parsed options, a property bag shared by all middleware, the cancellation token and the start time\. |
| [CurlMiddlewarePipeline](CurlDotNet.Middleware.CurlMiddlewarePipeline.md 'CurlDotNet\.Middleware\.CurlMiddlewarePipeline') | Runs curl requests through an ordered chain of [ICurlMiddleware](CurlDotNet.Middleware.ICurlMiddleware.md 'CurlDotNet\.Middleware\.ICurlMiddleware') \(logging, retry, caching, auth\.\.\.\) and then a final handler that actually executes the request\. |
| [CurlMiddlewarePipelineBuilder](CurlDotNet.Middleware.CurlMiddlewarePipelineBuilder.md 'CurlDotNet\.Middleware\.CurlMiddlewarePipelineBuilder') | Fluent builder that collects middleware \(built\-in or your own\) and a final handler, then produces a [CurlMiddlewarePipeline](CurlDotNet.Middleware.CurlMiddlewarePipeline.md 'CurlDotNet\.Middleware\.CurlMiddlewarePipeline') with [Build\(\)](CurlDotNet.Middleware.CurlMiddlewarePipelineBuilder.Build().md 'CurlDotNet\.Middleware\.CurlMiddlewarePipelineBuilder\.Build\(\)')\. |
| [LoggingMiddleware](CurlDotNet.Middleware.LoggingMiddleware.md 'CurlDotNet\.Middleware\.LoggingMiddleware') | Writes one log line when a request starts \(its command\) and one when it ends \(HTTP status and elapsed milliseconds, or the error message\), to the console or your own logger\. |
| [RateLimitMiddleware](CurlDotNet.Middleware.RateLimitMiddleware.md 'CurlDotNet\.Middleware\.RateLimitMiddleware') | Delays requests so that at most a given number complete in any one\-second window, to stay under an API's requests\-per\-second limit \(and avoid HTTP 429 responses\)\. |
| [RequestModifierMiddleware](CurlDotNet.Middleware.RequestModifierMiddleware.md 'CurlDotNet\.Middleware\.RequestModifierMiddleware') | Runs your synchronous action on the [CurlContext](CurlDotNet.Middleware.CurlContext.md 'CurlDotNet\.Middleware\.CurlContext') before each request, to add headers, change the URL or options, or stash values in [Properties](CurlDotNet.Middleware.CurlContext.Properties.md 'CurlDotNet\.Middleware\.CurlContext\.Properties')\. |
| [ResponseModifierMiddleware](CurlDotNet.Middleware.ResponseModifierMiddleware.md 'CurlDotNet\.Middleware\.ResponseModifierMiddleware') | Runs your asynchronous function on each [CurlResult](CurlDotNet.Core.CurlResult.md 'CurlDotNet\.Core\.CurlResult') after the request, to inspect, change or replace it \(for example to unwrap an envelope, redact a body or record metrics\)\. |
| [RetryMiddleware](CurlDotNet.Middleware.RetryMiddleware.md 'CurlDotNet\.Middleware\.RetryMiddleware') | Re\-runs the rest of the pipeline when a request fails transiently \(HTTP 5xx or 429 responses, DNS, connect, timeout and network errors\), waiting longer before each attempt \(exponential back\-off\)\. |
| [TimingMiddleware](CurlDotNet.Middleware.TimingMiddleware.md 'CurlDotNet\.Middleware\.TimingMiddleware') | Records how long the rest of the pipeline took and writes it to [Total](CurlDotNet.Core.CurlTimings.Total.md 'CurlDotNet\.Core\.CurlTimings\.Total') on the result and to `TimingStart`/`TimingEnd`/`TimingDuration` in [Properties](CurlDotNet.Middleware.CurlContext.Properties.md 'CurlDotNet\.Middleware\.CurlContext\.Properties')\. |
