## CurlMiddlewarePipelineBuilder Class

Fluent builder that collects middleware \(built\-in or your own\) and a final handler, then produces a
[CurlMiddlewarePipeline](CurlDotNet.Middleware.CurlMiddlewarePipeline.md 'CurlDotNet\.Middleware\.CurlMiddlewarePipeline') with [Build\(\)](CurlDotNet.Middleware.CurlMiddlewarePipelineBuilder.Build().md 'CurlDotNet\.Middleware\.CurlMiddlewarePipelineBuilder\.Build\(\)')\.

```csharp
public class CurlMiddlewarePipelineBuilder
```

Inheritance [System\.Object](https://learn.microsoft.com/en-us/dotnet/api/system.object 'System\.Object') &#129106; CurlMiddlewarePipelineBuilder

### Remarks

Middleware run in the order of the `Use...` calls: the first call is the outermost layer.
            [WithHandler\(Func&lt;CurlContext,Task&lt;CurlResult&gt;&gt;\)](CurlDotNet.Middleware.CurlMiddlewarePipelineBuilder.WithHandler(System.Func_CurlDotNet.Middleware.CurlContext,System.Threading.Tasks.Task_CurlDotNet.Core.CurlResult__).md 'CurlDotNet\.Middleware\.CurlMiddlewarePipelineBuilder\.WithHandler\(System\.Func\<CurlDotNet\.Middleware\.CurlContext,System\.Threading\.Tasks\.Task\<CurlDotNet\.Core\.CurlResult\>\>\)') is required; [Build\(\)](CurlDotNet.Middleware.CurlMiddlewarePipelineBuilder.Build().md 'CurlDotNet\.Middleware\.CurlMiddlewarePipelineBuilder\.Build\(\)') throws without it.
            The builder is not thread-safe; build once and share the resulting pipeline.

Example: `var pipeline = CurlMiddlewarePipeline.CreateBuilder().UseLogging(msg => logger.LogDebug(msg)).UseRetry(maxRetries: 3, delay: TimeSpan.FromSeconds(1)).UseRateLimit(10).WithHandler(ctx => Curl.ExecuteAsync(ctx.Command, ctx.CancellationToken)).Build();`

Guide: https://github.com/jacob-mellor/curl-dot-net/blob/master/docs/guides/logging-observability.md
