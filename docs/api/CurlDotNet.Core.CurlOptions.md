## CurlOptions Class

Every setting of one curl transfer as a typed object: the URL, method, headers, body, authentication,
timeouts, proxy, TLS, output files and diagnostics that a curl command line can express\.

```csharp
public class CurlOptions
```

Inheritance [System\.Object](https://learn.microsoft.com/en-us/dotnet/api/system.object 'System\.Object') &#129106; CurlOptions

### Example

```csharp
// curl -X POST -H "Content-Type: application/json" -d '{"name":"Ada"}' -m 10 https://api.example.com/users
var options = new CurlOptions
{
    Url = "https://api.example.com/users",
    Method = "POST",
    Data = "{\"name\":\"Ada\"}",
    MaxTime = 10
};
options.Headers["Content-Type"] = "application/json";
var result = await Curl.ExecuteAsync(options);
```

### Remarks

There are three ways to get one. (1) Parse a command: `Curl.Validate("curl -X POST -d a=1 https://api.example.com").ParsedOptions`
            returns the options exactly as the parser read them, which is the quickest way to see what a pasted command
            will send. (2) Use the fluent builder: `CurlRequestBuilder.Post(url).WithJson(body).GetOptions()`.
            (3) Set the properties yourself and run them with [ExecuteAsync\(CurlOptions\)](CurlDotNet.Curl.ExecuteAsync.md#CurlDotNet.Curl.ExecuteAsync(CurlDotNet.Core.CurlOptions) 'CurlDotNet\.Curl\.ExecuteAsync\(CurlDotNet\.Core\.CurlOptions\)'); nothing is
            parsed or shell-quoted then, so values containing quotes, `$` or spaces need no escaping.

Every property names the curl flag it corresponds to. Example: `curl -L -m 30 -H "Accept: application/json" https://api.example.com/items`
            is `new CurlOptions { Url = "https://api.example.com/items", FollowLocation = true, MaxTime = 30, Headers = { ["Accept"] = "application/json" } }`,
            and `await Curl.ExecuteAsync(options)` returns the same [CurlResult](CurlDotNet.Core.CurlResult.md 'CurlDotNet\.Core\.CurlResult') the command string would.

Hand-built options follow the classic rules: set [Method](CurlDotNet.Core.CurlOptions.Method.md 'CurlDotNet\.Core\.CurlOptions\.Method') to `"POST"` (or another
            method with a body) when you set [Data](CurlDotNet.Core.CurlOptions.Data.md 'CurlDotNet\.Core\.CurlOptions\.Data'), because a GET or HEAD built this way sends no body,
            whereas the parser picks POST for `-d` automatically.

Thread safety: an instance is not thread-safe. Executing it normalises [Url](CurlDotNet.Core.CurlOptions.Url.md 'CurlDotNet\.Core\.CurlOptions\.Url') and applies
            the process-wide `Curl.Default*` settings to it, so use one instance per request (or call
            [Clone\(\)](CurlDotNet.Core.CurlOptions.Clone().md 'CurlDotNet\.Core\.CurlOptions\.Clone\(\)')) instead of sharing one object between concurrent calls.

A few properties are recorded for compatibility but cannot be acted on (their remarks say so):
            [DnsServers](CurlDotNet.Core.CurlOptions.DnsServers.md 'CurlDotNet\.Core\.CurlOptions\.DnsServers'), [Interface](CurlDotNet.Core.CurlOptions.Interface.md 'CurlDotNet\.Core\.CurlOptions\.Interface'), [Quote](CurlDotNet.Core.CurlOptions.Quote.md 'CurlDotNet\.Core\.CurlOptions\.Quote'), [DisableEpsv](CurlDotNet.Core.CurlOptions.DisableEpsv.md 'CurlDotNet\.Core\.CurlOptions\.DisableEpsv') and
            [DisableEprt](CurlDotNet.Core.CurlOptions.DisableEprt.md 'CurlDotNet\.Core\.CurlOptions\.DisableEprt'), which the parser also lists in [UnsupportedOptions](CurlDotNet.Core.CurlOptions.UnsupportedOptions.md 'CurlDotNet\.Core\.CurlOptions\.UnsupportedOptions'), and the terminal-only
            [ProgressBar](CurlDotNet.Core.CurlOptions.ProgressBar.md 'CurlDotNet\.Core\.CurlOptions\.ProgressBar') and [ShowError](CurlDotNet.Core.CurlOptions.ShowError.md 'CurlDotNet\.Core\.CurlOptions\.ShowError'). The TLS options ([CaCertFile](CurlDotNet.Core.CurlOptions.CaCertFile.md 'CurlDotNet\.Core\.CurlOptions\.CaCertFile'), [CaPath](CurlDotNet.Core.CurlOptions.CaPath.md 'CurlDotNet\.Core\.CurlOptions\.CaPath'),
            [CertFile](CurlDotNet.Core.CurlOptions.CertFile.md 'CurlDotNet\.Core\.CurlOptions\.CertFile'), [KeyFile](CurlDotNet.Core.CurlOptions.KeyFile.md 'CurlDotNet\.Core\.CurlOptions\.KeyFile'), [PinnedPublicKey](CurlDotNet.Core.CurlOptions.PinnedPublicKey.md 'CurlDotNet\.Core\.CurlOptions\.PinnedPublicKey'), [Ciphers](CurlDotNet.Core.CurlOptions.Ciphers.md 'CurlDotNet\.Core\.CurlOptions\.Ciphers')) need .NET 5 or
            later; on .NET Standard 2.0 and .NET Framework they are listed in [UnsupportedOptions](CurlDotNet.Core.CurlOptions.UnsupportedOptions.md 'CurlDotNet\.Core\.CurlOptions\.UnsupportedOptions') as well.

How a command becomes a request: https://github.com/jacob-mellor/curl-dot-net/blob/master/docs/how-to/how-curldotnet-works/README.md
            and turning curl commands into C#: https://github.com/jacob-mellor/curl-dot-net/blob/master/docs/how-to/convert-curl-to-csharp/README.md
