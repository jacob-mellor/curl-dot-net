## CachingMiddleware\.ExecuteAsync\(CurlContext, Func\<Task\<CurlResult\>\>\) Method

### Remarks

A cache hit short-circuits: later middleware and the handler do not run.

Example: `var first = await pipeline.ExecuteAsync(ctx); var second = await pipeline.ExecuteAsync(new CurlContext { Command = ctx.Command });`
            sends one request when the first was a 200.
