## CurlHttpException\.IsRateLimited Property

True for 429 Too Many Requests: you are being rate limited; wait \(see [GetRetryAfter\(\)](CurlDotNet.Exceptions.CurlHttpException.GetRetryAfter().md 'CurlDotNet\.Exceptions\.CurlHttpException\.GetRetryAfter\(\)')\) before
sending more requests\.

```csharp
public bool IsRateLimited { get; }
```

#### Property Value
[System\.Boolean](https://learn.microsoft.com/en-us/dotnet/api/system.boolean 'System\.Boolean')  
True when [StatusCode](CurlDotNet.Exceptions.CurlHttpException.StatusCode.md 'CurlDotNet\.Exceptions\.CurlHttpException\.StatusCode') is 429\.

### Remarks

Example: `catch (CurlHttpException ex) when (ex.IsRateLimited) { await Task.Delay(ex.GetRetryAfter() ?? TimeSpan.FromSeconds(30)); }`
