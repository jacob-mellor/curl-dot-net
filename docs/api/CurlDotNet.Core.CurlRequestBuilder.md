## CurlRequestBuilder Class

Builds one HTTP request with chained, IntelliSense\-friendly methods \(one method per curl flag\)
and runs it with [ExecuteAsync\(CancellationToken\)](CurlDotNet.Core.CurlRequestBuilder.ExecuteAsync.md#CurlDotNet.Core.CurlRequestBuilder.ExecuteAsync(System.Threading.CancellationToken) 'CurlDotNet\.Core\.CurlRequestBuilder\.ExecuteAsync\(System\.Threading\.CancellationToken\)'); [ToCurlCommand\(\)](CurlDotNet.Core.CurlRequestBuilder.ToCurlCommand().md 'CurlDotNet\.Core\.CurlRequestBuilder\.ToCurlCommand\(\)') shows
the equivalent curl command\.

```csharp
public class CurlRequestBuilder
```

Inheritance [System\.Object](https://learn.microsoft.com/en-us/dotnet/api/system.object 'System\.Object') &#129106; CurlRequestBuilder

### Example

```csharp
var result = await CurlRequestBuilder
    .Get("https://api.example.com/users")
    .WithHeader("Accept", "application/json")
    .WithBearerToken(token)
    .WithTimeout(TimeSpan.FromSeconds(30))
    .ExecuteAsync();

// Same as: curl -H 'Accept: application/json' -H 'Authorization: Bearer ...' --max-time 30 https://api.example.com/users
```

### Remarks

Start with a factory for the HTTP method ([Get\(string\)](CurlDotNet.Core.CurlRequestBuilder.Get(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Get\(string\)'), [Post\(string\)](CurlDotNet.Core.CurlRequestBuilder.Post(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Post\(string\)'), [Put\(string\)](CurlDotNet.Core.CurlRequestBuilder.Put(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Put\(string\)'),
             [Patch\(string\)](CurlDotNet.Core.CurlRequestBuilder.Patch(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Patch\(string\)'), [Delete\(string\)](CurlDotNet.Core.CurlRequestBuilder.Delete(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Delete\(string\)'), [Head\(string\)](CurlDotNet.Core.CurlRequestBuilder.Head(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Head\(string\)') or [Request\(string, string\)](CurlDotNet.Core.CurlRequestBuilder.Request(string,string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.Request\(string, string\)') for any other verb),
             chain the options you need, then call [ExecuteAsync\(CancellationToken\)](CurlDotNet.Core.CurlRequestBuilder.ExecuteAsync.md#CurlDotNet.Core.CurlRequestBuilder.ExecuteAsync(System.Threading.CancellationToken) 'CurlDotNet\.Core\.CurlRequestBuilder\.ExecuteAsync\(System\.Threading\.CancellationToken\)') (or
             [Execute\(\)](CurlDotNet.Core.CurlRequestBuilder.Execute().md 'CurlDotNet\.Core\.CurlRequestBuilder\.Execute\(\)') from synchronous code). Every `With...` method returns the same builder, so
             the order of calls does not matter, and calling a method twice keeps the last value (headers are
             replaced by name, case-insensitively).

Each method maps to one curl flag: [WithHeader\(string, string\)](CurlDotNet.Core.CurlRequestBuilder.WithHeader(string,string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.WithHeader\(string, string\)') is `-H`, [WithData\(string\)](CurlDotNet.Core.CurlRequestBuilder.WithData(string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.WithData\(string\)')
             is `-d`, [WithBasicAuth\(string, string\)](CurlDotNet.Core.CurlRequestBuilder.WithBasicAuth(string,string).md 'CurlDotNet\.Core\.CurlRequestBuilder\.WithBasicAuth\(string, string\)') is `-u`, [WithTimeout\(TimeSpan\)](CurlDotNet.Core.CurlRequestBuilder.WithTimeout(System.TimeSpan).md 'CurlDotNet\.Core\.CurlRequestBuilder\.WithTimeout\(System\.TimeSpan\)') is `-m`, and so on;
             the remarks of every method name its flag. The request is executed by the same engine as
             [ExecuteAsync\(string\)](CurlDotNet.Curl.ExecuteAsync.md#CurlDotNet.Curl.ExecuteAsync(string) 'CurlDotNet\.Curl\.ExecuteAsync\(string\)'), so it behaves exactly like the curl command printed by
             [ToCurlCommand\(\)](CurlDotNet.Core.CurlRequestBuilder.ToCurlCommand().md 'CurlDotNet\.Core\.CurlRequestBuilder\.ToCurlCommand\(\)').

Example: `var result = await CurlRequestBuilder.Get("https://api.github.com/users/octocat").WithHeader("Accept", "application/json").WithTimeout(TimeSpan.FromSeconds(30)).ExecuteAsync();`
             is the same request as `curl -H 'Accept: application/json' --max-time 30 https://api.github.com/users/octocat`;
             then read `result.StatusCode` and `result.Body`.

Which API to use: paste a curl command into [ExecuteAsync\(string\)](CurlDotNet.Curl.ExecuteAsync.md#CurlDotNet.Curl.ExecuteAsync(string) 'CurlDotNet\.Curl\.ExecuteAsync\(string\)') when you have
             one from documentation; use this builder when the request is assembled in code (values from
             variables, conditional headers); use [LibCurl](CurlDotNet.Lib.LibCurl.md 'CurlDotNet\.Lib\.LibCurl') when many requests share
             the same defaults (base headers, token, timeout).

Thread safety: a builder is a mutable object for one request; do not share one instance
             between threads. Build a new one per request (they are cheap).

Tutorials: https://github.com/jacob-mellor/curl-dot-net/blob/master/docs/how-to/convert-curl-to-csharp/README.md
             and https://github.com/jacob-mellor/curl-dot-net/blob/master/docs/how-to/run-curl-command-in-csharp/README.md
